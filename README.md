Ejercicios de Python funcional
🧪 Ejercicio 1 – Saludo según nombre
Enunciado:
Pedile al usuario su nombre. Si se llama Cristian, saludalo de manera especial. Si no, saludalo normalmente.

🧪 Ejercicio 2 – Control de edad
Enunciado:
Preguntale al usuario cuántos años tiene.
•	Si tiene 18 o más, decile que puede ingresar.
•	Si tiene entre 13 y 17, decile que necesita ir acompañado.
•	Si tiene menos de 13, indicá que no puede ingresar.

🧪 Ejercicio 3 – Mayor de dos números
Enunciado:
Pedile al usuario que ingrese dos números. Indicá cuál es mayor o si son iguales.
