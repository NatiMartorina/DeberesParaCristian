Ejercicios Python
Ejercicios de Python funcional
🧪 Ejercicio 1 – Saludo según nombre
Enunciado:
Pedile al usuario su nombre. Si se llama Cristian, saludalo de manera especial. Si no, saludalo normalmente.

🧪 Ejercicio 2 – Control de edad
Enunciado:
Preguntale al usuario cuántos años tiene.
•	Si tiene 18 o más, decile que puede ingresar.
•	Si tiene entre 13 y 17, decile que necesita ir acompañado.
•	Si tiene menos de 13, indicá que no puede ingresar.

🧪 Ejercicio 3 – Mayor de dos números
Enunciado:
Pedile al usuario que ingrese dos números. Indicá cuál es mayor o si son iguales.

Ejercicio de clases
Crear la clase celular, asignarle sus atributos y las funciones. 


🧪 Ejercicio 4 – Clave secreta
Enunciado:
Pedile al usuario que ingrese una palabra secreta.

Si escribe "abrete sesamo", mostrá un mensaje de acceso concedido.

Si no, mostrá un mensaje de acceso denegado.

🧪 Ejercicio 5 – Categoría de edad
Enunciado:
Pedile al usuario su edad y clasificá su etapa de vida:

Si tiene 0 a 12 años, mostrá “Niñez”.

Si tiene entre 13 y 17, mostrá “Adolescencia”.

Si tiene entre 18 y 64, mostrá “Adultez”.

Si tiene 65 o más, mostrá “Tercera edad”.
